Daytona apt repository

Daytona is a Windows NT 4.0 style desktop for Debian 13 (trixie), on amd64 and arm64. This repository keeps it up to date with the rest of your system.

SuiteWhat it hasNewest
stableTagged releases@STABLE_VERSION@
edgeThe latest build of main, for testing@EDGE_VERSION@

1. Add the signing key

sudo curl -fsSLo /etc/apt/keyrings/daytona.gpg \
    https://jzume.github.io/Daytona/daytona-archive-keyring.gpg

Key fingerprint: 3AED 05B9 6FFE F7E8 7C6B 7249 6099 9388 8173 8EAD

2. Add the repository

Use Suites: stable for releases or Suites: edge for the latest build.

sudo tee /etc/apt/sources.list.d/daytona.sources <<'END'
Types: deb
URIs: https://jzume.github.io/Daytona
Suites: edge
Components: main
Signed-By: /etc/apt/keyrings/daytona.gpg
END

3. Install

sudo apt update
sudo apt install daytona

Log out and choose Daytona in the login screen's session menu. Updates then arrive with sudo apt update && sudo apt upgrade.

Notes

The edge suite only keeps the newest builds; older ones are removed. Every release and its packages stay on the releases page.
