Daytona apt repository

Daytona is a Windows NT 4.0 style desktop for Debian 13 (trixie), on amd64 and arm64. This repository keeps it up to date with the rest of your system.

1. Add the signing key

sudo curl -fsSLo /etc/apt/keyrings/daytona.gpg \
    https://jzu.me/daytona/daytona-archive-keyring.gpg

Key fingerprint: 3AED 05B9 6FFE F7E8 7C6B 7249 6099 9388 8173 8EAD

2. Add the repository

sudo tee /etc/apt/sources.list.d/daytona.sources <<'END'
Types: deb
URIs: https://jzu.me/daytona
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/daytona.gpg
END

For the latest build of main instead, write Suites: edge. To switch later, change that line in /etc/apt/sources.list.d/daytona.sources and run sudo apt update && sudo apt upgrade. Going from edge back to stable waits for the next release, since edge builds are newer.

3. Install

sudo apt update
sudo apt install daytona

Log out and choose Daytona in your login screen's session menu (GDM, SDDM and LightDM all list it). Updates then arrive with sudo apt update && sudo apt upgrade. Log out and back in after an update; your settings (colour scheme, wallpaper, taskbar) are kept.

The packages

daytonaThe shell, the Qt style, the session, and Daytona's own build of labwc (kept in /usr/libexec/daytona, so a system labwc is left alone). It recommends WirePlumber and pavucontrol-qt (volume), sound-theme-freedesktop and libcanberra-pulse (event sounds), UPower (battery), brightnessctl (brightness keys) and grim and wl-clipboard (Print Screen), which apt installs by default.
daytona-chicago95The Chicago95 theme, icons and cursors. Installed with daytona.
daytona-greeterOptional: a Windows 98-style log on screen for greetd (below).
daytona-dbgsymOptional: debug symbols, so crash backtraces show function names. Install it to report a crash.

Optional: the Daytona log on screen

daytona-greeter has a user name and password, a Session... button to pick any installed Wayland session and Shut Down.... It runs on the greetd login manager. Daytona works with any login manager and never installs it for you. To replace your current one (GDM, SDDM, LightDM):

sudo apt install daytona-greeter
sudo cp /usr/share/doc/daytona-greeter/examples/config.toml /etc/greetd/config.toml
systemctl status display-manager      # note which one is running now
sudo systemctl disable gdm3           # or sddm, lightdm: the one shown above
sudo systemctl enable --force greetd
sudo reboot

If you already have a greetd configuration, change only its [default_session] command to "daytona-greeter". On a high-density screen, use "daytona-greeter --scale 2" (any size from 1 to 3, such as 1.5).

To go back, run sudo systemctl disable greetd, then sudo systemctl enable --force gdm3 (or sddm, lightdm), and reboot. See docs/greeter.md for troubleshooting.

Notes

The edge suite keeps only the two newest builds; older ones are removed. Every release and its packages stay on the releases page, for installing by hand with sudo apt install ./daytona_*.deb ./daytona-chicago95_*.deb.
